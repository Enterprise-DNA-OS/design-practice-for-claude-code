# /approve-variation

Run:

```bash
node scripts/practice.mjs approve-variation <variation> <YYYY-MM-DD> <who approved it>
```

Ask who approved it if not given. Never invent it.

Use `--json` when combining results. On an ambiguous name, list the candidates and ask; never pick the first. Nothing here sends a message or takes a payment.
