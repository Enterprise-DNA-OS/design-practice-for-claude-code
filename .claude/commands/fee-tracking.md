# /fee-tracking

Run:

```bash
node scripts/practice.mjs fee-tracking
```

For each stage say how far ahead the burn is and what to do: update progress, raise a variation, or talk to the client. End with the stage to look at first.

Use `--json` when combining results. On an ambiguous name, list the candidates and ask; never pick the first. Nothing here sends a message or takes a payment.
