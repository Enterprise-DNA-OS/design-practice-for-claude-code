# /weekly-review

Run:

```bash
node scripts/practice.mjs weekly-review
```

Write it as a short memo: three headlines, then the tables, then the actions. Save to drafts/weekly-review-<date>.md.

Use `--json` when combining results. On an ambiguous name, list the candidates and ask; never pick the first. Nothing here sends a message or takes a payment.
